# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials, pairing URLs, project IDs, queries, or log content in a report. Use GitHub's private vulnerability reporting for this repository. If that option is unavailable, contact the repository owner privately through their GitHub profile.

Include the affected version or commit, impact, reproduction steps using synthetic data, and any suggested mitigation. Reports will be acknowledged and triaged as quickly as practical; no fixed response or disclosure timeline is guaranteed.

Only the latest version on the default branch receives security fixes before the project publishes versioned releases.
